ENGLISH ALFEA — ПОЛНЫЙ ПАКЕТ

В папке находятся все файлы, необходимые для публикации сайта:
- index.html — основной сайт
- manifest.json — PWA-манифест
- icon-192.svg — иконка 192x192

- service-worker.js — service worker

Для Netlify: загрузите всю папку или ZIP целиком через Netlify Drop.
Для GitHub Pages: загрузите содержимое этой папки в корень репозитория.
